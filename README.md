# Rowing-Boat-Placement-Code
This app helps rowing coaches decide which boat a rower should be placed in based on their 2K time, height, form rating, and weight.

## Real-World Problem
Coaches often need to compare rowers using several stats. This program makes the process quicker and more organized.

## How It Works
The user enters each rower’s:
- Name
- 2K time
- Height
- Form rating
- Weight

The program calculates a score and recommends a boat placement.

## Features
- Takes multiple rowers
- Converts 2K time into seconds
- Uses scoring logic
- Uses if/else statements
- Uses loops
- Uses multiple functions

## How to Run
1. Download the file `main.py`
2. Open it in a Python editor
3. Run the program
4. Enter the rower information
